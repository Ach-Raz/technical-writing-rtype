## 👾 Il Progetto

**Project Arrowhead** è uno sparatutto a scorrimento orizzontale, ricostruito da zero con moderne tecnologie web (HTML, CSS e JavaScript). Il nostro obiettivo è ricreare l'esperienza strategica, impegnativa e indimenticabile del capolavoro arcade del 1987.

Schiva il fuoco nemico, memorizza gli schemi d'attacco e padroneggia l'esclusiva meccanica del **"Force"** per farti strada attraverso le difese dell'impero Bydo. Non è solo uno sparatutto; è una prova di strategia e perseveranza.

---

## ✨ Funzionalità Chiave (MVP)

Basato sul nostro [Product Requirement Document (PRD)](/docs/PRD.md), l'MVP si concentra su:

*   **🚀 Movimento Classico:** Controlli fluidi e reattivi per l'iconica navicella R-9 "Arrowhead".
*   **💥 Cannone a Onde Ricaricabile:** Tieni premuto il pulsante di fuoco per scatenare un raggio devastante che trapassa i nemici.
*   **🛡️ Il Sistema "Force":** Aggancia questa unità indistruttibile alla tua nave per ottenere potenti potenziamenti o sganciala per farla agire come scudo e arma autonoma.
*   **👽 Nemici Sfidanti:** Affronta nemici implacabili e un enorme boss di fine livello, ognuno con schemi d'attacco unici.
*   **🏆 Sistema di Punteggio:** Competi per il primo posto, proprio come ai tempi delle sale giochi!

## 🚀 Come Iniziare

Per ottenere una copia locale e avviarla, segui questi semplici passaggi.

### Prerequisiti

Hai solo bisogno di un browser web moderno che supporti HTML5 e JavaScript.

### Installazione

1.  Clona il repository:
    ```sh
    git clone [URL_DEL_REPOSITORY_GIT]
    ```
2.  Naviga nella directory del progetto:
    ```sh
    cd project-arrowhead
    ```
3.  Apri il file `index.html` nel tuo browser. Fatto!

## 🎮 Controlli di Gioco

*   **Movimento:** Usa i `Tasti Freccia` o `WASD` per pilotare la navicella.
*   **Fuoco:** Premi la `Barra Spaziatrice` per sparare con l'arma standard.
*   **Carica Cannone:** Tieni premuta la `Barra Spaziatrice` per caricare il Cannone a Onde e rilascia per sparare.
*   **Gestione Force:** Premi `X` (o il tasto designato) per agganciare/sganciare il Force.
